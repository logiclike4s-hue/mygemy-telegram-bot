# Telegram Gemini bot

## Запуск

1. Установите Python 3.10+ и зависимости:

   ```bash
   python -m pip install -r requirements.txt
   ```

2. Скопируйте `.env.example` в `.env` и укажите токен бота из BotFather и
   ключ Google Gemini API.
3. Запустите:

   ```bash
   python bot.py
   ```

В личных чатах бот отвечает на каждое полученное сообщение. В группах он
отвечает только на reply к сообщению бота или на упоминание через `@username`.
Чтобы бот видел такие сообщения в группах, отключите Privacy Mode в @BotFather:
`/setprivacy` -> выберите бота -> `Disable`. История сохраняется отдельно для
каждого чата в локальном файле `bot_memory.sqlite3`, который не следует
загружать в GitHub.
Ответ Gemini передается потоково: бот начинает показывать текст сразу после
получения первых фрагментов.

## Файлы, голос и изображения

В личном чате бот может анализировать фотографии, документы, аудиофайлы и
голосовые сообщения. В группе вложение должно быть отправлено с упоминанием
`@username` или ответом на сообщение бота.

Для генерации изображения используйте:

```text
/image описание изображения
```

Модель генерации настраивается переменной `IMAGE_MODEL`. По умолчанию указана
`gemini-3.1-flash-image`; если эта модель недоступна для API-ключа, задайте в
переменных окружения модель, поддерживающую генерацию изображений.

## Режимы групп

Команды доступны администраторам группы:

```text
/mode one  — отвечать только на @username и ответы боту (по умолчанию)
/mode all  — отвечать на каждое сообщение группы
```

Режим сохраняется в файле `bot_memory.sqlite3`. Для режима `all` отключите
Privacy Mode через `/setprivacy` в @BotFather и выберите `Disable`.

## Отдельный админ-бот

Админ-бот запускается вместе с основным ботом, но использует отдельный токен.
Добавьте в `.env`:

```env
ADMIN_BOT_TOKEN=токен_админ-бота
ADMIN_USER_ID=5955636722
ADMIN_PASSWORD=ваш_пароль
INPUT_PRICE_PER_MILLION=0
OUTPUT_PRICE_PER_MILLION=0
```

Админ-бот доступен только пользователю с `ADMIN_USER_ID`. Сначала выполните
`/login <пароль>`. Команды:

```text
/stats                 — общая статистика
/stats @username       — статистика пользователя
/top                   — 10 пользователей с наибольшим числом запросов
/block <user_id или @username> — запретить обращаться к основному боту
/unblock <user_id или @username> — снять запрет для основного бота
/ban <chat_id> @user   — подготовить бан и запросить подтверждение
/confirm               — подтвердить последний бан
/unban <chat_id> <id>  — снять бан
```

`/block` — это глобальная блокировка в основном боте. Пользователь не сможет
писать ему в личных сообщениях и получать ответы в группах. Для блокировки в
конкретной Telegram-группе используйте `/ban`.

Для `/ban` админ-бот должен быть администратором группы с правом блокировки
пользователей. Стоимость показывается приблизительно по символам (около 4
символов на токен); укажите реальные цены модели в переменных окружения.
