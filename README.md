# Telegram Gemini bot

## Запуск

1. Установите Python 3.10+ и зависимости:

   ```bash
   python -m pip install -r requirements.txt
   ```

2. Скопируйте `.env.example` в `.env` и укажите токен бота из BotFather и
   ключ Google Gemini API.
3. Запустите:

   ```bash
   python bot.py
   ```

В личных чатах бот отвечает на каждое полученное сообщение. В группах он
отвечает только на reply к сообщению бота или на упоминание через `@username`.
Чтобы бот видел такие сообщения в группах, отключите Privacy Mode в @BotFather:
`/setprivacy` -> выберите бота -> `Disable`. История переписки хранится отдельно
для каждого чата в памяти процесса.
Ответ Gemini передается потоково: бот начинает показывать текст сразу после
получения первых фрагментов.

## Режимы групп

Команды доступны администраторам группы:

```text
/mode one  — отвечать только на @username и ответы боту (по умолчанию)
/mode all  — отвечать на каждое сообщение группы
```

Режим сохраняется в файле `bot_memory.sqlite3`. Для режима `all` отключите
Privacy Mode через `/setprivacy` в @BotFather и выберите `Disable`.
