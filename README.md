# Telegram Gemini bot

## Запуск

1. Установите Python 3.10+ и зависимости:

   ```bash
   python -m pip install -r requirements.txt
   ```

2. Скопируйте `.env.example` в `.env` и укажите токен бота из BotFather и
   ключ Google Gemini API.
3. Запустите:

   ```bash
   python bot.py
   ```

В личных чатах бот отвечает на каждое полученное сообщение. В группах он
отвечает только на reply к сообщению бота или на упоминание через `@username`.
Чтобы бот видел такие сообщения в группах, отключите Privacy Mode в @BotFather:
`/setprivacy` -> выберите бота -> `Disable`. История сохраняется отдельно для
каждого чата в локальном файле `bot_memory.sqlite3`, который не следует
загружать в GitHub.
Ответ Gemini передается потоково: бот начинает показывать текст сразу после
получения первых фрагментов.

## Поддерживаемые модели

На текущий момент проект настроен для работы с Google Gemini. В будущем
планируется расширение под несколько провайдеров:

- Google Gemini
- OpenAI ChatGPT
- DeepSeek
- Anthropic Claude

Для работы с внешними моделями потребуется отдельный ключ API для каждого
провайдера. Ключи хранятся только в `.env` или в переменных окружения хостинга,
не в GitHub-репозитории.

### Пример переменных окружения

```env
TELEGRAM_BOT_TOKEN=...
GEMINI_API_KEY=...
OPENAI_API_KEY=...
DEEPSEEK_API_KEY=...
ANTHROPIC_API_KEY=...

GEMINI_MODEL=gemini-3.5-flash-lite
IMAGE_MODEL=gemini-3.1-flash-image
OPENAI_MODEL=gpt-4o-mini
DEEPSEEK_MODEL=deepseek-chat
CLAUDE_MODEL=claude-3-5-haiku-latest
DEFAULT_PROVIDER=gemini
```

## Запуск на Render

Проект поддерживает Render Web Service через Telegram webhook. Создайте на
[Render](https://render.com/) новый **Web Service** из этого GitHub-репозитория:

```text
Build Command: pip install -r requirements.txt
Start Command: python bot.py
Plan: Free
```

Добавьте в Environment следующие переменные:

```env
TELEGRAM_BOT_TOKEN=...
GEMINI_API_KEY=...
ADMIN_BOT_TOKEN=...
ADMIN_USER_ID=...
ADMIN_PASSWORD=...
WEBHOOK_SECRET=случайная_строка_не_короче_16_символов
```

Render должен передать переменную `RENDER_EXTERNAL_URL` автоматически. Если её
нет в настройках сервиса, добавьте её вручную в виде URL сервиса, например
`https://mygemy-bot.onrender.com`. При её наличии бот использует webhook, а без
неё локально продолжает работать через polling.

Бесплатный сервис Render может засыпать после периода без запросов. Первый
ответ после пробуждения может прийти с задержкой.

## Файлы, голос и изображения

В личном чате бот может анализировать фотографии, документы, аудиофайлы и
голосовые сообщения. В группе вложение должно быть отправлено с упоминанием
`@username` или ответом на сообщение бота.

Для генерации изображения используйте:

```text
/image описание изображения
```

Модель генерации настраивается переменной `IMAGE_MODEL`. По умолчанию указана
`gemini-3.1-flash-image`; если эта модель недоступна для API-ключа, задайте в
переменных окружения модель, поддерживающую генерацию изображений.

## Режимы групп

Команды доступны администраторам группы:

```text
/mode one  — отвечать только на @username и ответы боту (по умолчанию)
/mode all  — отвечать на каждое сообщение группы
```

Режим сохраняется в файле `bot_memory.sqlite3`. Для режима `all` отключите
Privacy Mode через `/setprivacy` в @BotFather и выберите `Disable`.

## Команды бота

### Основной бот

```text
/start                          — приветствие и запуск бота
/model                          — показать текущий провайдер или сменить модель
/model gemini                  — переключиться на Gemini
/model openai                  — переключиться на OpenAI
/model deepseek                — переключиться на DeepSeek
/model claude                  — переключиться на Claude
/mode one                      — отвечать только на упоминания и ответы боту
/mode all                      — отвечать на все сообщения в группе
/image <описание изображения> — сгенерировать изображение
```

### Админ-бот

```text
/login <пароль>                — войти в админ-режим
/stats                         — общая статистика по всем пользователям
/stats <user_id или @username> — статистика конкретного пользователя
/top                           — топ 10 пользователей по числу запросов
/block <user_id или @username> — запретить пользователю обращаться к основному боту
/unblock <user_id или @username> — снять запрет для основного бота
/ban <chat_id> <user_id или @username> — подготовить бан пользователя в чате
/confirm                      — подтвердить последний бан
/unban <chat_id> <user_id>    — снять бан у пользователя в чате
/grantmodel <openai|deepseek|claude> <user_id или @username> — выдать спец-доступ к платной модели
/revokemodel <openai|deepseek|claude> <user_id или @username> — снять спец-доступ к платной модели
```

> Доступ к платным провайдерам `openai`, `deepseek` и `claude` выдаётся только администратором.

## Отдельный админ-бот

Админ-бот запускается вместе с основным ботом, но использует отдельный токен.
Добавьте в `.env`:

```env
ADMIN_BOT_TOKEN=токен_админ-бота
ADMIN_USER_ID=5955636722
ADMIN_PASSWORD=ваш_пароль
INPUT_PRICE_PER_MILLION=0
OUTPUT_PRICE_PER_MILLION=0
```

Админ-бот доступен только пользователю с `ADMIN_USER_ID`. Сначала выполните
`/login <пароль>`. Команды:

```text
/stats                 — общая статистика
/stats @username       — статистика пользователя
/top                   — 10 пользователей с наибольшим числом запросов
/block <user_id или @username> — запретить обращаться к основному боту
/unblock <user_id или @username> — снять запрет для основного бота
/ban <chat_id> @user   — подготовить бан и запросить подтверждение
/confirm               — подтвердить последний бан
/unban <chat_id> <id>  — снять бан
```

`/block` — это глобальная блокировка в основном боте. Пользователь не сможет
писать ему в личных сообщениях и получать ответы в группах. Для блокировки в
конкретной Telegram-группе используйте `/ban`.

Для `/ban` админ-бот должен быть администратором группы с правом блокировки
пользователей. Стоимость показывается приблизительно по символам (около 4
символов на токен); укажите реальные цены модели в переменных окружения.
